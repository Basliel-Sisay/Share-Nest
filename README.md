# Share-Nest

A community-focused resource-sharing platform built with Flutter (Dart) and Node.js.

## Demo Checklist (CRUD Operations)

This checklist covers the required CRUD operations for the project demonstration:

### 1. Create (Resource)
- [ ] Navigate to the Admin Dashboard.
- [ ] Add a new resource (e.g., "Power Drill").
- [ ] Verify the item appears in the "Browse" tab.

### 2. Read (Loans/Reservations)
- [ ] Login as a regular user.
- [ ] View "Sharing History" or "My Loans".
- [ ] Verify the UI displays your specific records.

### 3. Update (Loan Status)
- [ ] As an admin, update the status of a pending loan request.
- [ ] Verify the status change in the user's "My Loans" page.

### 4. Delete (Account/Resource)
- [ ] Navigate to Profile.
- [ ] Perform "Delete Account" to verify data persistence and database cleanup.
